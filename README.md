# FreeSkyVPN

Freemium VPN-сервис: головной сервер управляет заграничными нодами
(VLESS + Reality + XTLS Vision), MVP-клиент — Telegram-бот, дальше —
Android-приложение без выбора страны.

- [`head/`](head/) — головной сервер: FastAPI, PostgreSQL, устойчивое
  управление нодами, выбор конфигов, биллинг
- [`bot/`](bot/) — Telegram-бот, MVP-клиент поверх API головы
- [`android/`](android/) — Android-приложение: одна кнопка, тёмная тема,
  раздельное туннелирование российских сервисов
- [`provisioning/`](provisioning/) — разовый bootstrap новой ноды по SSH
- [`DEPLOY.md`](DEPLOY.md) — развёртывание на сервере: ключи, HTTPS, подключение ноды
- `smoke_test.py` — проверка развёрнутого стека по HTTP

Админка (ноды, пользователи, тарифы, SNI-пул, обновления Xray, события,
журнал действий) — часть головы, на `/admin`.

Установка на чистый сервер — один скрипт: `sudo ./install.sh`. Он спрашивает
только то, что знает человек (токен бота, ваш Telegram id, домен), остальное
настраивает сам и проверяет результат.

Полный чертёж (архитектура, схема данных, алгоритмы, roadmap) — отдельный
документ, см. историю разработки; актуальные технические решения по ходу
кодирования фиксируются в `head/README.md`.
