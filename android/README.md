# FreeSkyVPN — Android

Одна кнопка, тёмная тема, без выбора страны. Российские сервисы идут мимо
VPN. Доступ оплачивается вниманием: нажал «включить» — выбрал, на сколько
(15 мин / 1 ч / 2 ч), посмотрел рекламу. Подписки нет.

```
core/   чистый Kotlin: разбор vless://, сборка конфига Xray, раздельное
        туннелирование. Без Android SDK — тесты гоняются где угодно.
app/    Compose UI, VpnService, хранилище, клиент API головы.
```

## Собрать

```bash
cd android
./gradlew :app:assembleDebug
```

Перед первой сборкой нужно доложить три вещи, которых нет в Maven, —
см. [`app/libs/README.md`](app/libs/README.md):

1. `libXray.aar` — ядро Xray (MPL-2.0)
2. `libhev-socks5-tunnel.so` — tun2socks (MIT)
3. `geoip.dat` и `geosite.dat` — иначе правило `geoip:ru` не находит ничего

Без них проект собирается и запускается, но подключиться не может и честно
об этом сообщает.

## Настроить под свой сервер

Адрес головы и сервисный токен — в `app/build.gradle.kts`:

```kotlin
buildConfigField("String", "HEAD_API_URL", "\"https://api.вашдомен.ru\"")
```

Токен передаётся при сборке, чтобы не лежать в репозитории:

```bash
./gradlew :app:assembleRelease -PheadServiceToken=$(grep ^HEAD_SECRET_KEY ../.env | cut -d= -f2-)
```

HTTPS обязателен: Android по умолчанию запрещает открытый HTTP, а токен
пользователя не должен ходить по незашифрованному соединению.

## Как устроено раздельное туннелирование

Два независимых слоя, и каждый закрывает то, что не может другой.

**По назначению** — правила маршрутизации внутри конфига Xray
(`XrayConfigBuilder`). Основа — не список доменов, а правила по зонам:
`.ru`, `.su`, `.рф` — это и есть российский интернет, одно правило покрывает
сотни тысяч хостов и не требует сопровождения. К ним добавлены российские
сервисы на иностранных доменах (vk.com, 2gis.com, okko.tv) и `geoip:ru` для
трафика по голому IP. `geoip:private` оставляет доступной домашнюю сеть —
забыть про него значит сделать VPN, при котором пропадает принтер.

DNS тоже разделён: российские имена резолвятся российским резолвером
напрямую. Иначе российский домен вернёт зарубежную точку CDN, и «прямой»
маршрут окажется медленнее туннеля.

**По приложениям** — `VpnService.addDisallowedApplication`. Нужно ровно для
одного случая, который правилами не решается: приложение само проверяет,
поднят ли VPN, и отказывается работать. Так ведут себя несколько российских
банковских приложений. Список приходит с головы, сверяется с реально
установленными пакетами, и пользователь может переопределить его в обе
стороны.

`QUERY_ALL_PACKAGES` намеренно не запрашивается: Google Play выдаёт его
узкому списку категорий, VPN в него внятно не входит, а отклонённое
разрешение — это отклонённый релиз. Видимость приложений даёт блок
`<queries>` с фильтром launcher-интентов.

## Реклама

Это не украшение, а вся выручка: подписки нет, время покупается роликами.
Нажатие на кнопку без оплаченного времени открывает выбор длительности, и
ролики идут внутри того же жеста — пользователь нажал «включить», а не
«посмотреть рекламу, потом включить».

Три варианта, и каждый **говорит свою цену до выбора**: 15 минут за
пропускаемый ролик, час за один полный, два часа за два полных. Прятать
количество роликов до их начала — способ получить единицу в отзывах.

Время начисляется **за каждый просмотр**, а не за пакет целиком: кто
посмотрел первый из двух и вышел, оставляет себе час.

Когда время кончается, приложение само гасит туннель. Это вежливость, а не
защита: сессию реально заканчивает голова, убирая UUID клиента из конфига
ноды. Если время ещё есть, а пользователь выключил VPN сам — включает
обратно без рекламы.

`AdGateway` описывает интерфейс, `NoAds` пока ничего не показывает. Сборка
без рекламной сети полностью работоспособна: каждое подключение уходит по
запасному пути, голова записывает выдачи как `grace`, и в админке видно
флот, живущий целиком на резерве — что и происходит на самом деле.

**Ролик не загрузился — не повод не подключить.** Заполнение не бывает
стопроцентным. Если считать «нет рекламы» за «нет сервиса», авария
рекламной сети становится нашей, полной. Поэтому `Outcome.Unavailable` —
обычный исход, и ответ на него — короткий запасной доступ с меньшим
приоритетом: хуже настоящего, чтобы не стать способом пропустить ролик, но
не отказ.

**Какая сеть.** Google приостановил показ рекламы российским пользователям
в марте 2022, так что AdMob эту аудиторию не монетизирует. Остаются Яндекс
и VK. Это решает, какой SDK встанет за интерфейсом.

## Что проверено, а что нет

`core` собирается и проходит 44 теста. Это разбор ссылок, порядок правил
маршрутизации, DNS-разделение и разрешение списка приложений — то есть
места, где ошибка тихая: неверный порядок правил даёт конфиг, который Xray
примет и запустит, и всё будет выглядеть исправным, пока кто-нибудь не
откроет банк.

`app` не собирался ни разу: среда, в которой он написан, не имеет доступа к
`dl.google.com`, а значит ни к Android SDK, ни к AndroidX. XML проверены на
корректность, ссылки на ресурсы и импорты — статическим анализом. Всё
остальное в этом модуле нужно проверять на устройстве.
